# Daily Tools & Resources

A personal, reusable library of development packs, scripts, prompts and engineering resources.

## Resource catalog

| Pack | Purpose | Version |
| --- | --- | --- |
| [Vendor-independent harness](packs/vendor-independent-harness/README.md) | Shared engineering rules for Claude Code, Cursor, Codex and Antigravity | 1.0.0 |

[Download repository ZIP](https://github.com/AnkitParekh007/daily-tools-resources/archive/refs/heads/main.zip) or clone with Git. Each pack has its own instructions and installation entry point. Review code before running it.

## Adding resources

Use `packs/<name>/` for self-contained packs, with a README, version, prerequisites, installation, verification and removal instructions. Keep credentials and personal data out of this public repository. Prefer safe defaults and independently downloadable archives.
