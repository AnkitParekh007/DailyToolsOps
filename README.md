# Daily Tools & Resources

A reusable library of development packs, scripts, prompts and engineering resources.

## Resource catalog

| --- | --- | --- | --- |
| [Vendor-independent harness](packs/vendor-independent-harness/README.md) | Shared engineering rules for Claude Code, Cursor, Codex and Antigravity | 1.0.0 | [Installation & usage](packs/vendor-independent-harness/INSTRUCTIONS.md) |

[Download repository ZIP](https://github.com/AnkitParekh007/daily-tools-resources/archive/refs/heads/main.zip) or clone with Git. Each pack is self-contained. Review code before running it.

## Standard for new packs

Each `packs/<name>/` must contain README.md (overview and quick start), INSTRUCTIONS.md (prerequisites, download, installation, configuration, usage examples, validation, troubleshooting, upgrade and removal), VERSION, and a packaging entry point. Link instructions from both the pack README and this catalog. Keep credentials and personal data out of this public repository.
