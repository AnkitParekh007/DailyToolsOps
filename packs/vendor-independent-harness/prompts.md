# Daily prompts

## Implement
Read AGENTS.md and .harness/contract.md. Inspect the repository and task brief. Propose a focused plan, implement with tests, run verification, review the diff and record evidence. Stop before merge or deployment.

## Bug fix
Reproduce the defect, identify root cause, add a failing regression test, make the smallest correct fix and verify. Report reproduction and results.

## Independent review
Review the diff against the task and contract. Prioritize security, correctness and regressions. Cite file/line evidence and distinguish confirmed findings from hypotheses. Do not modify files unless asked.

## Release readiness
Inspect CI, tests, security, migration and rollback evidence. Report blockers and a go/no-go recommendation. Do not publish or deploy.
