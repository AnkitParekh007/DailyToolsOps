# Implementation roadmap

Phase 1: catalog, manifest, local CLI, validation, packaging, CI. Existing pack URLs stay stable. Public release publishing, install ownership tracking, upgrade and uninstall automation remain future work.

Phase 2: context engineering, repository intelligence, specification-driven development, production readiness, code review, security audit, UI/UX, bug investigation.

Phase 3: agent starter, MCP, RAG, guardrails, evaluation, observability, cost and reliability.

Phase 4: repository maintainer, technology intelligence, CI/CD, release engineering, handoff and documentation.

Phase 5: framework extensions, bundles, searchable catalog and contributor ecosystem.

Each pack must include concrete artifacts, individual instructions, tests and safe installation. No pack is considered released until validation and review pass.
