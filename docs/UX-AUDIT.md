# UX audit — redesign

Design reference: GoDocs by Themefisher (Dribbble shot 10175793), published palette #FBFBFB, #D70716, #0C1323, #573C45 and #E79FAB. Adapted dark theme and semantic surfaces; no copied illustrations.

Remediations: sticky navigation with anchor offsets, explicit icon theme selectors with accessible names and pressed state, system preference and persistence, one-shot typewriter with static screen-reader text and reduced-motion fallback, category icons, consistent card actions, responsive grids, skip link, visible focus, optional support panel with provided coffee profile and GitHub Sponsors URL. Sponsor account activation is not verified. Keyboard shortcut Ctrl/Cmd+K focuses search.

Acceptance: run existing archive tests plus browser checks for search, theme, navigation, responsive overflow, downloads and reduced motion. Do not claim visual or live deployment verification unless observed.
